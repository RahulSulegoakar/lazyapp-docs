<Update label="2026-08-22" description="v1">

**Webhook resume and secret rotation.** Paused endpoints can be turned back on with `POST /v1/webhooks/{webhook}/resume`. Lost signing secrets can be rotated with `POST /v1/webhooks/{webhook}/rotate-secret` without deleting the endpoint. Listing now includes `pause_reason`.

**Inbound media download.** `GET /v1/messages/{message}/media` returns the bytes of media a contact sent in. Returns `409` while the download is still queued.

**Contact consent API.** `POST /v1/contacts/{contact}/consent` records consent collected outside LazyApp — for example from a website opt-in box. Granting marketing consent lifts a matching suppression.

**Starter template sets.** `GET /v1/templates/sets` lists the template sets this installation supports. Pass `template_set` when creating a setup link.

**`customers:act` scope.** Platforms can act on a customer's behalf with `X-LazyApp-Customer` without holding `customers:write`.

**Stable send refusal codes.** Refused sends now include a `code` — `customer_service_window_closed`, `contact_suppressed`, `marketing_opt_out`, or `no_connection`. Contacts report `service_window` on read.

</Update>

<Update label="2026-08-19" description="v1 · breaking, pre-launch">

**One shape for one object.** The Platform API wrapped single objects in a `data`
envelope while every other single-object response was bare. All of them are bare now;
`data` wraps lists only. See [conventions](/concepts/conventions#response-shape).

**Every `DELETE` answers `204`.** Four endpoints previously returned `200` with
`{"deleted": true}` or `{"cancelled": true}`. A successful delete has no body.

**`GET /v1/workflows` cursor-paginates** like every other list, so a workspace with
more than 100 workflows can read all of them.

<Note>
  These three are breaking, and they are shipping before the API has integrators.
  Nothing after this point changes an existing response shape inside `v1` — see
  [versioning](/reference/versioning).
</Note>

</Update>

<Update label="2026-08-19" description="v1">

**Idempotency on every write.** `Idempotency-Key` is now honoured on all `/v1` write endpoints, not just messages and events. A retry replays the recorded response; reusing a key with a different body is refused. See [idempotency](/concepts/idempotency).

**Cursor pagination everywhere.** Broadcasts, events, media, templates, flows, scheduled messages and webhook endpoints now paginate like contacts and conversations, so a caller with more than one page can reach all of it.

**Media access history.** `GET /v1/media/{media}` returns `access_history` — who read, uploaded or deleted a file, when, and from where. The history outlives the asset.

**Events accept workspace-defined types and contact recipients.** `type` now validates against the event definitions in your workspace, and `recipient.type: contact_id` addresses a contact directly.

**`contact_information_request`.** Ask a contact for a phone number inside a conversation and have the reply attach to their record.

**Added `GET /v1/capabilities`** so clients can check what a connection supports instead of hard-coding assumptions.

**Scheduled sending.** `send_at` and `ttl_seconds` on `POST /v1/messages`, plus `GET` and `DELETE /v1/messages/scheduled`.

**Added** `/v1/templates`, `/v1/contacts`, `/v1/conversations`, `/v1/workflows`, `/v1/broadcasts`, `/v1/webhooks` and `/v1/flows`.

**Added the Meta-compatible proxy** at `/meta/whatsapp/{version}/...`. See [migrating](/migrating/from-cloud-api).

**Added `POST /v1/integrations/{source}/events`** for external systems.

**Every response now carries** `X-RateLimit-*` and `X-LazyApp-Api-Version`.

</Update>
