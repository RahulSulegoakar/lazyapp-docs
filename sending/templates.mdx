A template is pre-approved content. It is the only way to message someone outside the 24-hour customer-service window, so most production traffic is templates.

Templates belong to your workspace and mode — there is no `accountId` query parameter. LazyApp submits to Meta on the connected WABA for that workspace.

## Quick start

```bash
# List approved and pending templates
curl "https://lazyapp.in/v1/templates?status=approved" \
  -H "Authorization: Bearer $LAZYAPP_API_KEY"

# Create and submit to Meta (default)
curl https://lazyapp.in/v1/templates \
  -H "Authorization: Bearer $LAZYAPP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "order_shipped",
    "language": "en",
    "category": "UTILITY",
    "body_text": "Hi {{1}}, order {{2}} ships today and arrives {{3}}.",
    "body_examples": ["Asha", "1042", "Thursday"],
    "footer_text": "Reply STOP to opt out",
    "submit": true
  }'
```

## List templates

[`GET /v1/templates`](/api-reference/templates/list-templates) returns cursor-paginated templates for the workspace.

| Query | Filters |
| --- | --- |
| `status` | `draft`, `pending`, `approved`, `rejected`, `paused`, `disabled`, … |
| `category` | `UTILITY`, `AUTHENTICATION`, `MARKETING` |
| `limit` | Page size (max 200) |

Response fields include `uuid`, `name`, `language`, `category`, `status`, `body_text`, `header`, `buttons`, `rejection_reason`, `quality_score`, and Meta's `provider_template_id` when assigned.

Retrieve one template by name or uuid: [`GET /v1/templates/{template}`](/api-reference/templates/retrieve-a-template).

## Categories

Meta requires one of three, and it drives pricing:

| Category | For | Notes |
| --- | --- | --- |
| `UTILITY` | Order updates, appointment reminders, receipts | Cheapest. Must relate to an existing transaction |
| `AUTHENTICATION` | One-time passcodes | Use [Verify](/sending/verify) rather than building this yourself |
| `MARKETING` | Offers, announcements, re-engagement | Required for [broadcasts](/sending/broadcasts). Most expensive |

<Warning>
  Meta re-categorises templates it judges to be miscategorised, which changes what you pay.
  A promotional message dressed as a utility template will be moved to marketing, and you
  receive a `template.category_changed` [webhook](/webhooks/events).
</Warning>

## Create a template

LazyApp uses a **flat native shape** on `POST /v1/templates`, not Zernio's Meta `components` array on `/whatsapp/templates`:

```bash
curl https://lazyapp.in/v1/templates \
  -H "Authorization: Bearer $LAZYAPP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "order_shipped",
    "language": "en",
    "category": "UTILITY",
    "body_text": "Hi {{1}}, order {{2}} ships today and arrives {{3}}.",
    "body_examples": ["Asha", "1042", "Thursday"],
    "footer_text": "Reply STOP to opt out",
    "submit": true
  }'
```

Rules:

- Names: lowercase letters, digits, underscores only (`^[a-z0-9_]+$`), unique per language in the workspace.
- `body_examples`: one realistic string per `{{n}}` placeholder — Meta rejects templates it cannot evaluate.
- `submit`: defaults to `true` (submit immediately). Pass `"submit": false` to keep a local draft.

### Headers and buttons

```json
{
  "header": { "format": "TEXT", "text": "Order update" },
  "buttons": [
    { "type": "URL", "text": "Track", "url": "https://acme.example/track/{{1}}" },
    { "type": "QUICK_REPLY", "text": "Talk to support" }
  ]
}
```

`header.format` is `NONE`, `TEXT`, `IMAGE`, `VIDEO` or `DOCUMENT`. Button types: `QUICK_REPLY`, `URL`, `PHONE_NUMBER`, `OTP`, `FLOW`. URL buttons must be `https://`.

Authentication templates can pass:

```json
{
  "authentication": {
    "add_security_recommendation": true,
    "code_expiration_minutes": 10
  }
}
```

### Meta-shaped create (proxy)

If you already have Kapso/Cloud API payloads, create via the proxy with Meta's `components` envelope:

```bash
curl -X POST "https://lazyapp.in/meta/whatsapp/v21.0/{waba_id}/message_templates" \
  -H "Authorization: Bearer $LAZYAPP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "order_confirmation",
    "language": "en",
    "category": "UTILITY",
    "components": [
      { "type": "BODY", "text": "Hi {{1}}, your order {{2}} has been confirmed!" }
    ]
  }'
```

See [Migrating from Cloud API](/migrating/from-cloud-api).

## Template statuses

Only `approved` templates can be sent. LazyApp stores lowercase statuses mapped from Meta:

| `status` | Meaning |
| --- | --- |
| `draft` | Saved in LazyApp, not submitted |
| `submitting` | In flight to Meta |
| `pending` | Under Meta review (includes Meta `IN_APPEAL`) |
| `approved` | Sendable |
| `rejected` | Declined — read `rejection_reason`, fix, resubmit (often under a new name) |
| `paused` | Paused on quality grounds — temporarily unsendable |
| `disabled` | Disabled by Meta — not sendable |
| `archived` | Archived at Meta |
| `deleted` | Deleted locally / pending deletion at Meta |

<Note>
Meta review usually takes minutes but can take up to 24 hours. Do not poll the list in a tight loop — subscribe to template [webhooks](/webhooks/events).
</Note>

### Webhooks

| Event | When |
| --- | --- |
| `template.pending` | Submitted to Meta |
| `template.approved` | Approved and sendable |
| `template.rejected` | Declined (`rejection_reason`) |
| `template.paused` | Quality pause |
| `template.disabled` | Disabled after repeated problems |
| `template.category_changed` | Meta moved category (pricing impact) |

## Starter template sets

Platforms can seed templates when a customer connects via [`template_set` on setup links](/platform/setup-links#starter-templates). Discover valid keys:

```bash
curl https://lazyapp.in/v1/templates/sets \
  -H "Authorization: Bearer $LAZYAPP_API_KEY"
```

Returns named packs (for example `real_estate`) with template names and languages — do not hardcode keys across deployments.

## Sync and delete

Pull changes made in Meta Business Manager:

```bash
curl -X POST https://lazyapp.in/v1/templates/sync \
  -H "Authorization: Bearer $LAZYAPP_API_KEY"
```

LazyApp also updates statuses from Meta webhooks; sync is for reconciliation.

Delete at Meta and mark deleted locally:

```bash
curl -X DELETE https://lazyapp.in/v1/templates/{name_or_uuid} \
  -H "Authorization: Bearer $LAZYAPP_API_KEY"
```

## What we skip (Zernio-style)

| Zernio | LazyApp |
| --- | --- |
| `GET /whatsapp/templates?accountId=` | `GET /v1/templates` (workspace scoped) |
| Meta `components` on native create | Flat `body_text`, `header`, `buttons` on `/v1/templates` |
| Template Library API (`library_template_name`, `template-library` lookup) | Create in Meta's library in Business Manager, then `POST /v1/templates/sync` |
| `whatsapp.template.status_updated` event name | `template.approved`, `template.rejected`, etc. |
