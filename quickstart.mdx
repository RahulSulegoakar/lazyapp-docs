title: "Quickstart"
description: "From nothing to a delivered WhatsApp message."
---

You will create an API key, send a message, and receive the delivery status on a webhook.

## Prerequisites

- A LazyApp account and a workspace. Sign up at [lazyapp.in](https://lazyapp.in).
- A connected WhatsApp number, or the sandbox number that comes with a new workspace.
- A phone you can receive WhatsApp on, to be the recipient.

<Steps>
  <Step title="Create an API key">
    In the Developer Console, open **Settings → API keys** and create a key.

    Keys are shown once, at creation. Copy it straight into your secret store.

    Use a `sk_test_` key while you build. Test keys never reach a real phone, so you
    cannot accidentally message a customer while wiring things up.

    <Warning>
      Never put a key in frontend code. If you need to call LazyApp from a browser, see
      [embedded components](/platform/embedded-components).
    </Warning>
  </Step>

  <Step title="Say hello">
    Every request is Bearer-authenticated and returns JSON.

    <CodeGroup>
    ```bash cURL
    curl https://lazyapp.in/v1/messages \
      -H "Authorization: Bearer $LAZYAPP_API_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: quickstart-1" \
      -d '{
        "type": "text",
        "to": "+919812345670",
        "body": "Hello from LazyApp."
      }'
    ```

    ```js Node
    const response = await fetch('https://lazyapp.in/v1/messages', {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${process.env.LAZYAPP_API_KEY}`,
        'Content-Type': 'application/json',
        'Idempotency-Key': 'quickstart-1',
      },
      body: JSON.stringify({
        type: 'text',
        to: '+919812345670',
        body: 'Hello from LazyApp.',
      }),
    });

    const message = await response.json();
    ```

    ```python Python
    import os, requests

    response = requests.post(
        "https://lazyapp.in/v1/messages",
        headers={
            "Authorization": f"Bearer {os.environ['LAZYAPP_API_KEY']}",
            "Idempotency-Key": "quickstart-1",
        },
        json={"type": "text", "to": "+919812345670", "body": "Hello from LazyApp."},
    )

    message = response.json()
    ```

    ```php PHP
    $response = Http::withToken(env('LAZYAPP_API_KEY'))
        ->withHeader('Idempotency-Key', 'quickstart-1')
        ->post('https://lazyapp.in/v1/messages', [
            'type' => 'text',
            'to' => '+919812345670',
            'body' => 'Hello from LazyApp.',
        ]);
    ```
    </CodeGroup>

    A `201` means LazyApp accepted and sent it:

    ```json
    {
      "uuid": "9f8b1c2d-4e5f-4a6b-8c7d-0e1f2a3b4c5d",
      "request_id": "req_01J9Z4K7Q0",
      "status": "sent",
      "acceptance_status": "accepted",
      "type": "text",
      "provider_message_id": "wamid.HBgMOTE5ODEyMzQ1Njcw",
      "error_message": null
    }
    ```

    <Note>
      A free-form text message only reaches someone inside the 24-hour
      customer-service window — that is, after they message you. Outside it, send an
      approved [template](/sending/templates) instead. LazyApp enforces this server-side,
      so a send outside the window fails with a clear error rather than silently vanishing.
    </Note>
  </Step>

  <Step title="Receive the result">
    Sending is only half of it. Register an endpoint to hear what happened:

    ```bash
    curl https://lazyapp.in/v1/webhooks \
      -H "Authorization: Bearer $LAZYAPP_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "url": "https://example.com/webhooks/lazyapp",
        "subscribed_events": ["message.delivered", "message.read", "message.failed"]
      }'
    ```

    The response includes a signing `secret`, shown once. Use it to
    [verify every delivery](/webhooks/verifying) before you trust the body.

    Leave `subscribed_events` out to receive [everything](/webhooks/events).
  </Step>

  <Step title="Go live">
    Swap the `sk_test_` key for `sk_live_`. Nothing else changes.

    Before you do, check
    [`GET /v1/capabilities`](/concepts/capabilities) to confirm the number you are
    sending from is connected and what it supports.
  </Step>
</Steps>
