LazyApp is one WhatsApp API for developers, SaaS platforms, and businesses: send messages and templates, receive signed webhooks, run OTP verify, broadcasts, and flows — and white-label the same platform for your own customers. This page takes you from API key to a confirmed send — about five minutes.

**Base URL:** `https://lazyapp.in`

<Info>
  **Building a product where your users connect *their* WhatsApp numbers?** The send loop below is the same, but you'll want one workspace per platform customer, scoped keys, and webhook routing — start at the [platform guide](/platform/overview) after your first message.
</Info>

---

## Authentication

All API requests require an API key as a Bearer token. There is no official SDK yet — every example below is plain HTTP.

### Get your API key

1. [Sign up](https://lazyapp.in) or log in
2. Open **Settings → API keys**
3. Click **Create API key**
4. Copy the key immediately — you won't be able to see it again

Use a `sk_test_` key while you build. Test keys never reach a real phone.

### Set up the client

<CodeGroup>
```bash cURL
export LAZYAPP_API_KEY="sk_test_..."

curl https://lazyapp.in/v1/capabilities \
  -H "Authorization: Bearer $LAZYAPP_API_KEY"
```

```js Node
const LAZYAPP_API_KEY = process.env.LAZYAPP_API_KEY;

const response = await fetch('https://lazyapp.in/v1/capabilities', {
  headers: { Authorization: `Bearer ${LAZYAPP_API_KEY}` },
});

const { data } = await response.json();
```

```python Python
import os, requests

LAZYAPP_API_KEY = os.environ["LAZYAPP_API_KEY"]

response = requests.get(
    "https://lazyapp.in/v1/capabilities",
    headers={"Authorization": f"Bearer {LAZYAPP_API_KEY}"},
)

data = response.json()["data"]
```

```php PHP
$response = Http::withToken(env('LAZYAPP_API_KEY'))
    ->get('https://lazyapp.in/v1/capabilities');

$data = $response->json('data');
```
</CodeGroup>

**Key format:** `sk_test_` or `sk_live_` plus 40 characters. Keys are stored as SHA-256 hashes — they're only shown once at creation.

**Security tips:** Use environment variables, create separate keys per app, grant the narrowest [scopes](/reference/scopes), and rotate periodically. See [Authentication](/authentication).

<Warning>
  Never put a key in frontend code. If you need LazyApp in a browser, see
  [embedded components](/platform/embedded-components).
</Warning>

## Key concepts

- **Workspace** — Your team tenant. Your API key belongs to exactly one workspace; you never pass a workspace id.
- **Mode** — `live` or `test`, taken from the key prefix. Test never reaches a real phone. Data in the two modes never mixes.
- **Connection** — A WhatsApp Business Account plus its phone numbers inside the workspace.
- **Message** — Anything you send or receive. Addressed by a stable `uuid`.
- **Webhook** — How LazyApp pushes delivery, reads, replies, and template status to you.

IDs in this API are UUIDs (like `9f8b1c2d-4e5f-4a6b-8c7d-0e1f2a3b4c5d`). Each step below returns what the next step needs.

## Step 1: Confirm a connection

You need at least one WhatsApp connection on the workspace. Connect a number in the console, or claim a LazyApp sandbox number in test mode.

Then list what you have:

<CodeGroup>
```bash cURL
curl https://lazyapp.in/v1/capabilities \
  -H "Authorization: Bearer $LAZYAPP_API_KEY"
```

```js Node
const response = await fetch('https://lazyapp.in/v1/capabilities', {
  headers: { Authorization: `Bearer ${process.env.LAZYAPP_API_KEY}` },
});

const { data } = await response.json();

for (const connection of data) {
  console.log(`${connection.display_phone_number}: ${connection.connection_uuid}`);
}
// → +919812345670: 9f8b1c2d-4e5f-4a6b-8c7d-0e1f2a3b4c5d
```

```python Python
result = requests.get(
    "https://lazyapp.in/v1/capabilities",
    headers={"Authorization": f"Bearer {os.environ['LAZYAPP_API_KEY']}"},
).json()

for connection in result["data"]:
    print(f"{connection['display_phone_number']}: {connection['connection_uuid']}")
# → +919812345670: 9f8b1c2d-4e5f-4a6b-8c7d-0e1f2a3b4c5d
```

```php PHP
$data = Http::withToken(env('LAZYAPP_API_KEY'))
    ->get('https://lazyapp.in/v1/capabilities')
    ->json('data');

foreach ($data as $connection) {
    echo "{$connection['display_phone_number']}: {$connection['connection_uuid']}\n";
}
```
</CodeGroup>

```json
{
  "data": [
    {
      "connection_uuid": "9f8b1c2d-4e5f-4a6b-8c7d-0e1f2a3b4c5d",
      "phone_number_id": "123456789012345",
      "display_phone_number": "+919812345670",
      "is_default": true,
      "capabilities": {
        "messages.text": true,
        "messages.template": true
      }
    }
  ]
}
```

Most sends use the default connection automatically. Pass `phone_number_id` or `connection_uuid` only when you have several. See [Capabilities](/concepts/capabilities).

## Step 2: Send your first message

<CodeGroup>
```bash cURL
curl https://lazyapp.in/v1/messages \
  -H "Authorization: Bearer $LAZYAPP_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: quickstart-1" \
  -d '{
    "type": "text",
    "to": "+919812345670",
    "body": "Hello from LazyApp."
  }'
```

```js Node
const response = await fetch('https://lazyapp.in/v1/messages', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.LAZYAPP_API_KEY}`,
    'Content-Type': 'application/json',
    'Idempotency-Key': 'quickstart-1',
  },
  body: JSON.stringify({
    type: 'text',
    to: '+919812345670',
    body: 'Hello from LazyApp.',
  }),
});

const message = await response.json();
console.log('Message sent:', message.uuid);
```

```python Python
message = requests.post(
    "https://lazyapp.in/v1/messages",
    headers={
        "Authorization": f"Bearer {os.environ['LAZYAPP_API_KEY']}",
        "Idempotency-Key": "quickstart-1",
    },
    json={
        "type": "text",
        "to": "+919812345670",
        "body": "Hello from LazyApp.",
    },
).json()

print(f"Message sent: {message['uuid']}")
```

```php PHP
$message = Http::withToken(env('LAZYAPP_API_KEY'))
    ->withHeader('Idempotency-Key', 'quickstart-1')
    ->post('https://lazyapp.in/v1/messages', [
        'type' => 'text',
        'to' => '+919812345670',
        'body' => 'Hello from LazyApp.',
    ])
    ->json();

echo "Message sent: {$message['uuid']}\n";
```
</CodeGroup>

A `201` means LazyApp accepted and sent it:

```json
{
  "uuid": "9f8b1c2d-4e5f-4a6b-8c7d-0e1f2a3b4c5d",
  "request_id": "req_01J9Z4K7Q0",
  "status": "sent",
  "acceptance_status": "accepted",
  "type": "text",
  "provider_message_id": "wamid.HBgMOTE5ODEyMzQ1Njcw",
  "error_message": null
}
```

Save the `uuid` — you need it for the next step.

<Note>
  A free-form text message only reaches someone inside the 24-hour customer-service
  window — after they message you. Outside it, send an approved
  [template](/sending/templates) instead. LazyApp enforces this server-side, so a send
  outside the window fails with a clear error rather than silently vanishing.
</Note>

## Step 3: Confirm it worked

Fetch the message back — its `status` tells you where it is in the pipeline:

<CodeGroup>
```bash cURL
curl "https://lazyapp.in/v1/messages/MESSAGE_UUID" \
  -H "Authorization: Bearer $LAZYAPP_API_KEY"
```

```js Node
const check = await fetch(
  `https://lazyapp.in/v1/messages/${message.uuid}`,
  { headers: { Authorization: `Bearer ${process.env.LAZYAPP_API_KEY}` } },
).then((r) => r.json());

console.log(check.status);
// → sent
```

```python Python
check = requests.get(
    f"https://lazyapp.in/v1/messages/{message['uuid']}",
    headers={"Authorization": f"Bearer {os.environ['LAZYAPP_API_KEY']}"},
).json()

print(check["status"])
# → sent
```

```php PHP
$check = Http::withToken(env('LAZYAPP_API_KEY'))
    ->get("https://lazyapp.in/v1/messages/{$message['uuid']}")
    ->json();

echo $check['status']; // sent
```
</CodeGroup>

`status` moves through `queued` → `sent` → `delivered` → `read` (or `played` / `failed`). You'll also see the message in the [console](https://lazyapp.in). Prefer [webhooks](/webhooks/overview) for production instead of polling.

**That's the whole loop** — connection, send, confirmation. Everything else is variations on this.

## One endpoint, every send mode

The same `POST /v1/messages` call covers immediate sends, scheduling, and every message type:

| You set | Result |
| --- | --- |
| No `send_at` | Sends immediately (`201`) |
| `send_at` (+ optional `ttl_seconds`) | Schedules for later (`202`) |
| `type: "template"` | Works outside the 24-hour window |
| `type: "text"` / media / interactive / … | Free-form, window must be open |

```json
{
  "type": "template",
  "to": "+919812345670",
  "template": { "name": "appointment_reminder", "language": "en" },
  "send_at": "2026-09-02T09:00:00+05:30",
  "ttl_seconds": 3600
}
```

Message types, media, reactions, and quoting are covered in [Messages](/sending/messages).

## Step 4: Receive status on a webhook

Register an endpoint so delivery and reads push to you:

<CodeGroup>
```bash cURL
curl https://lazyapp.in/v1/webhooks \
  -H "Authorization: Bearer $LAZYAPP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://yourapp.example/webhooks/lazyapp",
    "subscribed_events": ["message.delivered", "message.read", "message.failed"]
  }'
```

```js Node
await fetch('https://lazyapp.in/v1/webhooks', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.LAZYAPP_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://yourapp.example/webhooks/lazyapp',
    subscribed_events: ['message.delivered', 'message.read', 'message.failed'],
  }),
});
```

```python Python
requests.post(
    "https://lazyapp.in/v1/webhooks",
    headers={"Authorization": f"Bearer {os.environ['LAZYAPP_API_KEY']}"},
    json={
        "url": "https://yourapp.example/webhooks/lazyapp",
        "subscribed_events": [
            "message.delivered",
            "message.read",
            "message.failed",
        ],
    },
)
```

```php PHP
Http::withToken(env('LAZYAPP_API_KEY'))
    ->post('https://lazyapp.in/v1/webhooks', [
        'url' => 'https://yourapp.example/webhooks/lazyapp',
        'subscribed_events' => ['message.delivered', 'message.read', 'message.failed'],
    ]);
```
</CodeGroup>

The response includes a signing `secret`, shown once. Use it to [verify every delivery](/webhooks/verifying) before you trust the body. Leave `subscribed_events` out to receive [everything](/webhooks/events).

## Beyond messaging

Sending is the entry point. The same API key opens the rest of WhatsApp on LazyApp.

### Send a template outside the window

<CodeGroup>
```bash cURL
curl https://lazyapp.in/v1/messages \
  -H "Authorization: Bearer $LAZYAPP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "template",
    "to": "+919812345670",
    "template": {
      "name": "order_shipped",
      "language": "en",
      "category": "utility",
      "components": [
        {
          "type": "body",
          "parameters": [
            { "type": "text", "text": "1042" }
```
